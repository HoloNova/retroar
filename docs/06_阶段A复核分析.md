# 阶段 A：原始结果复核与研究决策

本次只分析已完成实验，不训练、不修改训练代码或原始指标。本文修正此前报告中对 ar_matched 和研究优先级的过强解释。

## 1. 完整性

已核对 40 个 result.json：8 个模式 × 5 个种子均完成 5000 步，停止原因均为 max_steps；数据与训练源码指纹和 suite.json 一致；各版本评估同一 256 题测试集；同一种子的初始权重指纹一致。多种子是在相同数据划分上重复训练，并非五个独立数据集。

## 2. 结果与稳定性

| 方法 | 整题正确率（种子均值±标准差） |
|---|---:|
| ar | 76.95 ± 3.55% |
| ar_matched（重复相同计算） | 77.34 ± 4.23% |
| extra_compute（额外监督但不更新历史） | 74.14 ± 1.36% |
| hard（边生成边改） | 84.53 ± 1.19% |
| soft（边生成边改） | 88.05 ± 2.50% |
| soft_feedback（保留概率但不回改） | 73.98 ± 4.87% |
| posthoc_hard（写完再改） | 88.28 ± 1.27% |
| posthoc_soft（写完再改） | 92.50 ± 1.15% |

关键配对差异（百分点，种子 0～4）：

- posthoc_soft − soft：7.81、6.25、1.17、2.73、4.30；均值 +4.45，5/5 为正。
- posthoc_soft − posthoc_hard：4.69、1.95、3.13、5.47、5.86；均值 +4.22，5/5 为正。
- soft − hard：0.39、−0.39、7.03、6.64、3.91；均值 +3.52，4/5 为正，但前两个接近打平。
- soft_feedback 在 5/5 种子上低于 ar；仅保留概率不是普遍有效的策略。

这些是描述性证据，不是统计显著性证明。尤其首轮已使用种子 0～2 和同一测试集，阶段 A 不是完全独立复现。后续确认性实验应使用事先固定的新划分，并排除旧数据的同构题。

## 3. 修改确实纠错，但不是越改越好

跨五个种子合计的旧位置事件：

| 方法 | 错改对 | 对改错 | 净事件数 |
|---|---:|---:|---:|
| hard | 246 | 67 | 179 |
| soft | 217 | 53 | 164 |
| posthoc_hard | 298 | 85 | 213 |
| posthoc_soft | 333 | 80 | 253 |

事件不是独立题目：同一位置可以被反复修改。online 统计不含当步新位置，posthoc 统计全体位置；不能直接比较事件总量断言效率。soft 最终成绩高于 hard，但净旧位置纠错事件更少，说明最终优势不能简单解释为“改对次数更多”，还可能来自初始草稿、更少初始错误或当前位置更新。需完整测试集轨迹而非当前三道示例才能分解原因。

概率质量也不是全面改善：online soft 的平均 Brier 为 0.0637（hard 为 0.0705，越低越好），但交叉熵为 0.1592（hard 为 0.1546）。不能声称 soft 在所有不确定性指标上都更好。posthoc_soft 两项分别为 0.0457、0.1202，在这两项上均优于 posthoc_hard 的 0.0585、0.1319；这也不等于已证明概率校准。

## 4. 必须修正的公平性解释

### ar_matched 不是有效利用预算的强基线

model.py 在相同状态下重复调用无 dropout 的模型，并重复相同交叉熵，最后将所有 loss 平均。数学上它与普通 ar 的平均目标相同，第二次计算没有提供新的信息或搜索；数值计算路径差异可能累积为训练轨迹差异，但具体来源未单独验证。

因此它只是冗余计算的负对照。此前“严格计算匹配 AR”“单纯增加计算几乎没有收益”的说法过强，应改为：**重复相同计算没有稳定收益；尚未验证普通 AR 有效使用同样预算后的能力。**

强基线可将预算用于更多训练更新，或多候选生成及公开图约束评分。两者分别匹配训练预算和推理预算，不应混称。评分不能使用测试标准答案，评分开销也须计入。调用次数相同不等于严格 FLOPs、监督或延迟相同。

### posthoc 与 online 不只是修订时机不同

online 的六次修订分别监督 1、2、3、4、5、6 个位置，共 21 个位置目标；posthoc 六次各监督 6 个位置，共 36 个位置目标。算上六次单位置生成目标，总计为 27 与 42，且每次交叉熵先平均再对调用平均，因此差异是监督覆盖和各位置权重，不只是简单放大 loss。

推理时 posthoc 也有更多完整序列更新机会。其优势可能来自完整草稿、更均匀的修订预算分配、监督覆盖等，当前没有分离。证据足以说“这套 posthoc 实现更好”，不足以说“在线修订必然较差”。

## 5. 与最初研究问题的关系

用户最初关心的是模型自己继续构思并回改，不一定有外部新信息。当前完整图任务与这一动机相容：它测试进一步计算和草稿修订，不测试流式外部证据。把 delayed-evidence 强行变成唯一下一步会更换研究问题。

当前较稳妥结论：

> 在一个完整条件已知的小图任务中，可修订草稿的训练/推理方案有积极信号；本设置下写完后的概率修订表现最好，在线修订的独特收益未被证实。

还不能声称新范式、自然语言效果或严格等计算优势。已有迭代细化和连续/软状态工作，单一配色任务的提升不足以与前人工作区分。

## 6. 建议的下一阶段（尚未执行）

优先维持原研究问题，做一轮小而严格的确认，而非扩大模型或继续延长相同训练：

1. 把 ar_matched 降为冗余计算诊断；加入真正利用额外训练/推理预算的普通生成基线。
2. 固定或匹配 online/posthoc 的监督覆盖与损失权重，明确其修改预算差异。
3. 在独立题目划分上确认 posthoc soft 相对 hard 的收益；记录全测试集首次草稿、逐轮概率、修改事件和最终结果。
4. 如果优势仍在，围绕“概率草稿何时比确定草稿更适合迭代修订”深化，并核对该具体问题的前人工作；若优势消失，记录边界或停止，不为追求区分度无限加机制。

若用户另外选择在线流式方向，再设计外部延迟证据任务。必须给“不回改但等同样久再回答”的方法相同证据、截止时间和预算；否则只会证明多等线索有用。该方向与自主构思任务应分开报告。
