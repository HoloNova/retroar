# 证据总表

本表汇总五轮主要实验的全部关键数字，用于支撑收尾判断（文档 13）。机器可读版本（含每个变体的种子列表、
前向调用数、样本来源路径）由 `scripts/collect_evidence.py` 从 `results/` 生成，见
`results/evidence_table.json` 与 `results/evidence_table.md`。

指标统一为**整题准确率**：一道题六个自由点全部填对才算正确。除非另有说明，数字都是测试集
（256 题），并标注种子数。

> 注意：`stage_b_v1` 与 `belief_v1` 的训练配置为 `evaluate_test: false`，因此其
> `result.json` 记录的是**验证集**分数；正式数字一律取各自目录下的 `serial_test.json`。
> 采集脚本按此规则区分，避免混用。

## 1. 首轮长实验 `results/long_v1`（3 种子 × 5000 步）

| 方法 | 整题准确率 | 说明 |
|---|---:|---|
| 概率草稿回改 | 87.37% | 边生成边改 |
| 确定草稿回改 | 85.03% | 边生成边改 |
| 普通生成 | 77.47% | 6 次前向 |
| 多算一次但不改历史 | 74.09% | 后经复核，属冗余计算诊断 |
| 概率反馈但不回改 | 75.78% | 概率仅用于反馈 |

结论：回改出现积极信号，但“多算一次”对照方式不足以支撑“同等算力下更优”的说法。

## 2. 阶段 A `results/stage_a_v1`（5 种子 × 5000 步）

| 方法 | 整题准确率 |
|---|---:|
| 写完再改 + 概率草稿 | 92.50% |
| 写完再改 + 确定草稿 | 88.28% |
| 边生成边改 + 概率草稿 | 88.05% |
| 边生成边改 + 确定草稿 | 84.53% |
| 重复相同输入的额外前向 | 77.34% |
| 普通生成 | 76.95% |
| 概率反馈但不回改 | 73.98% |

结论：写完再改在 5/5 种子上优于边生成边改；概率草稿的优势尚不稳定；`ar_matched` 只是
重复同一输入，不能代表“有效利用额外算力”。

## 3. 阶段 B `results/stage_b_v1`（5 个新种子 × 5000 步）

| 方法 | 整题准确率 | 每题前向调用 |
|---|---:|---:|
| 写完再改 + 概率草稿 | 93.36% | 12 |
| 写完再改 + 确定草稿 | 90.86% | 12 |
| 边生成边改 + 概率草稿 | 85.23% | 12 |
| 边生成边改 + 确定草稿 | 84.69% | 12 |
| 普通生成 + 2 候选采样 | 82.03% | 12 |
| 普通生成 + 4 候选采样 | 86.25% | 24 |
| 双倍训练步数 + 2 候选 | 81.09% | 12 |
| 双倍训练步数 + 4 候选 | 83.44% | 24 |

结论：在相同前向预算下，写完再改仍明显领先；多候选采样追不上；把预算花在“多训练”上
没有收益。修订能修好的错题比例同样支持这一点。

## 4. 草稿信念 `results/belief_v1`（5 个新种子；状态温度 T）

| 方法 | 整题准确率 | 状态熵（上限 1.099 nats） |
|---|---:|---:|
| 写完再改 T=2 | 94.53% | 0.152 |
| 写完再改 T=1 | 93.83% | 0.026 |
| 写完再改 T=4 | 92.34% | 0.567 |
| 写完再改 T=8 | 86.09% | 0.926 |
| 写完再改 + 确定草稿 | 90.39% | — |
| 边生成边改 T=1 | 84.92% | 0.026 |
| 边生成边改 T=2 | 83.67% | 0.152 |
| 边生成边改 + 确定草稿 | 83.05% | — |
| 边生成边改 T=4 | 80.78% | 0.567 |
| 边生成边改 T=8 | 75.39% | 0.926 |

结论：温度确实把草稿从近似 one-hot 压平成真正的不确定分布，因此“分布塌缩导致 soft 与 hard
无差别”这一解释被排除；但概率草稿在任何温度下都没有达到事前约定的继续标准，压得越平越差、
方差越大。这限定了这一表示干预，不构成对全部 categorical belief 机制的反驳。

## 5. 延迟证据收尾 `results/delayed_v1`（5 个新种子，单次线索揭示）

| 方法 | 整题准确率 | 每题有效前向 |
|---|---:|---:|
| 概率草稿回改 | 90.23% | 12 |
| 确定草稿回改 | 80.16% | 12 |
| 等线索齐后生成 2 候选 | 79.53% | 12 |
| 等线索齐后生成 | 74.45% | 6 |
| 丢弃草稿、空状态迭代求解 | 66.64% | 6 |

配对差值（描述性，5 种子双边符号检验最小 p=0.0625）：

- 确定草稿回改 − 等线索齐后生成：**+5.70pp**，5/5 为正。
- 确定草稿回改 − 丢弃草稿重新求解：**+13.52pp**，5/5 为正。
- 确定草稿回改 − 等线索齐后的两候选：**+0.62pp，仅 2/5 为正**（事前主要继续条件失败）。
- 概率草稿回改 − 确定草稿回改：**+10.08pp**，5/5 为正（真实配置差异，需独立重复）。

便宜的诊断对照（每个模型在同一批测试题上）：

| 对照 | 整题准确率范围 |
|---|---:|
| 直接提交早期草稿 | 0.08% – 0.70% |
| 早期草稿的六种整体颜色置换中取最优 | 2.42% – 3.83% |
| 晚期也不揭示线索 | 0.94% – 4.84% |

结论：早期草稿本身结构往往不正确（置换修复也救不回来），“回改”相对于更强对照没有独特优势。

## 6. soft 高分是否依赖旧草稿：事后推理诊断

不追加训练。固定这 5 个已训练的 soft 模型，只在第一轮晚期调用前替换草稿状态，其余
（图条件、位置、present 标记、模型参数、后续六轮求解）完全不变。复现脚本：
`scripts/analyze_delayed_probe.py`；输出：`results/delayed_v1/posthoc_state_probe.json`。

| 第一轮晚期看到的草稿 | 最终整题准确率 |
|---|---:|
| 固定均匀 1/3、1/3、1/3 | 90.39% |
| 所有自由点颜色向量置零（present 仍保留） | 90.63% |
| 本题原始 soft 草稿 | 90.23% |
| 同批另一道题的草稿 | 89.92% |
| 本题草稿取 argmax 变 one-hot | 86.80% |

早期草稿实测熵约 1.087–1.092 nats（上限 1.099），平均最大概率约 0.378–0.387，即几乎不含
题目相关信息。

**窄结论：这些已训练 soft 模型的最终成绩对早期草稿的具体内容几乎不敏感**，因此不能把 90%
归因于“先构思出有用的草稿再据新证据修正”。边界：这是对已训练模型的事后输入干预，不是
从头训练的 restart_soft 对照，也未独立重复；`zeros` 保留了 present 标记，不等价于空状态
起始的 `restart_hard`。缺少独立训练的 restart_soft 是本条最明确的缺口。

## 7. 如何核对这些数字

```bash
.venv/bin/python -m scripts.collect_evidence      # 重建 results/evidence_table.{json,md}
.venv/bin/python -m scripts.analyze_delayed_probe # 重建第 6 节的诊断（约 1 分钟）
```

每个数字都能在 `results/<实验>/<变体>_seed<N>/serial_test.json` 中找到原始记录；每个运行的
数据与源码指纹、最佳步数、停止原因见同目录的 `result.json` / `metadata.json` / `status.json`。
