## 推荐阅读顺序

1. **英文快速理解**：[`docs/en/README.md`](en/README.md) → [英文结果说明](en/results.md)。
2. **只想看中文结论**：[13_收尾实验与可行性总结](13_收尾实验与可行性总结.md) → [14_证据总表](14_证据总表.md)。
3. **想看这个想法本身**：[01_研究构想与交接说明](01_研究构想与交接说明.md)。
4. **想看它怎么被否掉**：03 → 05 → 07 → 09 → 11（每轮运行前固定的协议），再配 04、06、08、10。
5. **想看数据**：`results/evidence_table.json`（机器可读）与各实验目录下的 `report.md`。

## 阅读时需要知道的三件事

- 全部结论都来自一个**六点三色图、约三万参数、2 核 CPU**的小模型，不能外推到语言模型。
- 该任务可被回溯搜索 100% 解出，因此这里的准确率只用于**比较机制**，不证明实用性。
- 每轮协议都是运行前落盘的；后一轮可以推翻前一轮的判读，但不能改写前一轮的记录。
